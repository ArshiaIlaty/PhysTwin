Contributing to the Project Website

This site lives in docs/ and deploys via GitHub Pages from the main branch.

Enable GitHub Pages (one-time)

  1. Push the docs/ folder to main.
  2. Repo → Settings → Pages.
  3. Source: Deploy from branch → branch main, folder /docs.
  4. Site URL: https://arshiailaty.github.io/PhysTwin/

Sync Arshia’s figures after re-running experiments

bash docs/sync_assets.sh
git add docs/
git commit -m "Update website assets"
git push

Malak — add closed-loop results

1. Export rollout metrics

After a closed-loop policy rollout, export per-step forces to CSV (columns: target_force, achieved_force). Template: arshia_work/malak_closed_loop_forces_TEMPLATE.csv.

2. Generate comparison figure

python plot_open_closed_force_comparison.py \
  --closed_loop_csv arshia_work/malak_closed_loop_forces.csv

Copy output to docs/assets/malak/achieved_vs_target.png (or update open_vs_closed_force.png in arshia assets).

3. Add policy rollout video

Render sim video of the policy driving the gripper. Save as docs/assets/malak/policy_rollout.mp4.

4. Update docs/index.html

Replace the placeholder <div class="placeholder"> blocks in the #closed-loop section with:

<figure class="figure">
  <img src="assets/malak/achieved_vs_target.png" alt="Achieved vs target force">
  <p class="caption">Closed-loop force tracking on cloth.</p>
</figure>

<figure class="figure">
  <video controls width="100%">
    <source src="assets/malak/policy_rollout.mp4" type="video/mp4">
  </video>
  <p class="caption">Policy rollout in PhysTwin.</p>
</figure>

5. Add metrics table (optional)

Insert a table under the closed-loop section with MAE, success rate, or replay vs novel-target results.

File layout

docs/
├── index.html          # main page — edit sections here
├── CONTRIBUTING.html   # this page
├── css/style.css
├── js/main.js
├── sync_assets.sh      # copy figures from arshia_work/
└── assets/
    ├── arshia/         # forward force + scenario plots
    ├── malak/          # closed-loop plots + videos (Malak adds here)
    └── phystwin/       # teaser + force GIFs from upstream

Tips

  • Keep images under ~2 MB for fast loading; compress PNGs if needed.
  • Prefer MP4 (H.264) for videos; host large files on YouTube and embed if >25 MB.
  • Both contributors can edit docs/index.html — use distinct sections (#open-loop, #closed-loop).
