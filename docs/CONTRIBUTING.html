Contributing to the Project Website

This site lives in docs/ and deploys via GitHub Pages from the main branch.

Enable GitHub Pages (one-time)

  1. Push the docs/ folder to main.
  2. Repo → Settings → Pages.
  3. Source: Deploy from branch → branch main, folder /docs.
  4. Site URL: your GitHub Pages URL for this repo (Settings → Pages).

Sync scenario-sweep figures after re-running experiments

bash docs/sync_assets.sh
git add docs/
git commit -m "Update website assets"
git push

Add closed-loop results

1. Export rollout metrics

After a closed-loop policy rollout, export per-step forces to CSV (columns: target_force, achieved_force). Template: scenario_sweeps/closed_loop_forces_TEMPLATE.csv.

2. Generate comparison figure

python plot_open_closed_force_comparison.py \
  --closed_loop_csv scenario_sweeps/closed_loop_forces.csv

Copy output to docs/assets/force_control/achieved_vs_target.png.

3. Add policy rollout video

Render sim video of the policy driving the gripper. Save as H.264 MP4 under docs/assets/force_control/videos/ (or run docs/convert_videos_for_web.py).

4. Update docs/index.html

Add figures and videos under the #closed-loop section using paths under assets/force_control/.

File layout

docs/
├── index.html          # main page — edit sections here
├── CONTRIBUTING.html   # this page
├── css/style.css
├── js/main.js
├── sync_assets.sh      # copy figures from scenario_sweeps/
├── convert_videos_for_web.py
└── assets/
    ├── scenario_sweeps/  # counterfactual physics + forward ML plots/videos
    ├── force_control/    # closed-loop policy plots + videos
    └── phystwin/         # teaser + force GIFs from upstream

Tips

  • Keep images under ~2 MB for fast loading; compress PNGs if needed.
  • Use H.264 MP4 for videos (OpenCV mp4v does not play in browsers — run the converter script).
  • Preview locally: cd docs && python3 -m http.server 8080, then open in a browser (not the IDE file preview).
